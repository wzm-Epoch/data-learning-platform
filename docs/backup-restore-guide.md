# 进度备份与恢复

## 日常操作

固定使用 http://127.0.0.1:4173 。设置→导出学习进度JSON；下载由用户主动发起，浏览器决定保存目录，建议放D盘。网页不会后台自动写磁盘。备份不含课程、原始数据或临时练习文字。

导入时选择文件或粘贴JSON，最大1 MiB。选择合并或替换，再预览变化步骤、完成项目数、总进度和迁移提示。合并逐条取较新更新时间，同时间保留本地记录；事件去重保留最近100条。替换会更新状态、事件、位置、前置知识确认和偏好。

点击“确认执行导入”；替换还需页内“确认替换本地记录”，可以取消。预览后记录改变或其他标签更新时，重新读取并预览。重置先显示范围、勾选备份确认，再点击“再次确认并重置”。不删除课程或原始项目。

页内二次确认是本轮针对原生弹窗阻塞的修正，已通过构建；最终浏览器复测尚未执行，不写成已经通过。

## 故障与迁移

保存失败会说明仅在内存，并提供立即导出按钮；不要立即关闭该页。存储被禁用、隐私模式结束、清理浏览器均可能导致丢失。

损坏或未知版本记录不会自动覆盖。先导出原始恢复副本供排错，再明确替换有效普通备份或重置；原始恢复副本不是直接可导入的普通备份。不要手动修改版本号绕过校验。

存储键da-learning:progress:v1，schemaVersion=1，当前内容版本0.6.0。旧0.4.0/0.3.0在允许版本列表内，仍须通过完整结构和稳定ID校验。文字修订保留完成；实质方法、代码或数据变化标待复习；删除步骤通过映射归档。合并依赖本机时间，时钟回拨或人为修改备份时间可能影响判断。
