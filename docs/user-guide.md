# 用户指南

版本0.6.0，2026-11-17。面向已有Python/DataFrame基础的个人本机学习者。

## 启动与停止

已验证Windows x64、Node.js 24.18.0、npm 11.16.0。生产学习只需Node，不需要Python或联网安装依赖；已提供dist，没有免安装exe。

双击工程根目录“启动学习平台.cmd”，或在工程执行 `npm.cmd start`，访问 http://127.0.0.1:4173 。在启动终端按Ctrl+C停止。端口占用会明确退出，不自动换端口；不要随意结束其他进程。不要双击dist/index.html。不同浏览器、localhost与不同端口的记录互不共享。

## 找到课程

首页可以继续最近有效步骤。项目库支持名称、原名称、核实技术搜索，以及分类、难度、资源和学习状态筛选。12分类、29项目，P21包含两课。路线分别列出知识硬前置和项目建议顺序，允许主动跳转。

“已发布内容完整可学”表示当前阅读、代码、结果说明和练习齐备，不表示原模型端到端复现。部分可学项目的具体缺口见known-issues.md。原保存结果、新教学计算和浏览器确定性派生分别标示，网页不运行Python或重训模型。

## 学习与交互

同一步显示对应讲解、来源单元代码、数据/图与自评。手机使用讲解/代码/结果标签；代码和长表局部滚动。图表提供键盘图例与同源表；筛选仅限已有结果支持的维度，缩放不改变全量分母。重置恢复筛选、图例和视窗。来源弹窗支持Tab循环和Esc关闭。

打开页面只记录位置，不自动表示掌握。主动开始，练习自评“我能解释”后再标记完成；自评不是考试评分。项目按有效必修步骤计算，总进度按可学习项目等权平均，同时展示完整完成数和内容覆盖数。未开放项目不计入分母。

保存步骤、自评、位置、前置知识确认、偏好及最多100条主动事件。练习文字只在当前步骤临时保留，不进入备份。主题、字号与备份在设置页。详见backup-restore-guide.md。
