## 实际实现

- `storage.ts` 导出统一storageAdapter；引擎位于 `engine.mjs`，React上下文在 `ProgressProvider.tsx`。首页、项目库/分类、项目总览、步骤目录、路线、记录页共用同一状态，项目库与记录页支持学习状态筛选。
- `localStorage`键 `da-learning:progress:v1`：schemaVersion=1、contentVersion、revision、updatedAt、复合稳定ID的stepStates、最近位置、偏好、前置知识自我确认、最近100条主动学习事件及删除归档。项目和课节完成布尔值不另存，课节通过步骤清单可直接查看。无学习时长估计、云同步、账户、后端或数据库。练习文字仅在当前步骤临时保留，不在持久存储与备份范围。
- 步骤支持未开始、进行中、完成、待复习。仅打开页面保存位置，不新增主动学习事件、不自动完成。每步必修练习自评“我能解释”后才能主动完成；自评为“还需练习”可将已完成步骤降为待复习；恢复未开始会清除该步自评。
- 单项目比例=有效必修步骤完成数/有效必修步骤数，完成要求每步完成及对应必修练习自评通过；P21两课合计12步。总进度=可学习项目比例的等权平均；同时显示完整完成数/29、可学习覆盖数/29。零必修/未开放项目单列，不加入分母；空分母有明确文案。
- 推荐优先真实待复习/进行中步骤，再考虑用户主动确认的知识前置、建议先学项目的完成情况与入门顺序。知识确认不由项目完成自动推断。建议先学项目只是排序依据，不是解锁门槛，允许直接跳转。
- 页面偏好和最近位置进入统一适配。只有新进度键不存在时才尝试读取第三阶段位置/第一阶段偏好；旧键保留、不反复恢复。重置写入空的新版本记录，因此旧位置不会复活。未删除原数据键或课程文件。

## 备份、恢复与保护

设置页可主动下载普通进度JSON，以及故障时的原始存储恢复副本。浏览器决定下载目录，平台不宣称自动写磁盘，建议用户将备份放D盘。恢复副本保存原字符串，供排错，不是直接可导入的普通备份。

支持文件或粘贴JSON，最大1 MiB、步骤及归档合计最多2000项、事件最多100条；校验结构、schemaVersion、允许课程版本、枚举、时间、复合ID一致性、未知ID、未知位置/事件和额外字段。导入是JSON解析与受控数据处理，不执行HTML或脚本。未知/较新版本拒绝，原存储不改。已损坏/不兼容的原存储处于保护状态，普通保存不能覆盖；先导出原始副本，再由用户明确替换/重置。

导入先选择合并或替换、显示变化步骤数/完整项目数/总进度前后值与迁移说明，再确认执行。预览后本页变化会要求重新预览；磁盘变化会被写前快照检查拒绝。合并按逐步骤更新时间取较新值，同时间保留当前存储；事件去重保留最近100条，位置、偏好和知识确认取较新备份。替换另有确认，重置要求范围说明、勾选确认和再次确认，不涉及课程或原始文件。

跨标签页监听storage事件，明确提示读取最新或合并本页；写前比较原始存储字符串。Web Locks可用时，同来源所有写入和读取-修改-写入操作在同一锁内串行。写入失败时保留内存更改并提供立即导出按钮，不仅记录控制台。

## 迁移与内容维护

`content-source/progress-policy.json`声明可接受旧课程版本、步骤必修/适用性覆盖以及删除映射。build生成`content/progress-manifest.json`，只取课节和步骤均ready且适用的步骤。目前385步及对应自评明确为必修。

- 标题、讲解等纯文字变化保留完成，新增步骤没有虚假记录。
- 原代码片段、教学修正代码、输入SHA-256、结果数据/图表定义改变会改变语义指纹，将已有学习状态标待复习并清除练习确认。
- 方法解释本身实质变更而代码数据不变时，维护者必须增加步骤的semanticRevision；平台不自动判断自然语言含义。
- 删除必须登记旧复合ID映射到新ID或null；原记录归档、排除分母，有替代步骤时转为待复习。旧ID永不复用。当前发布没有人为删除或变更课程步骤；增删/方法变化通过独立测试夹具验证，没有篡改真实学习史。
- 迁移即时在内存生效，下次成功保存落盘；迁移提示与导出可用。未知ID无映射时拒绝读取/导入并保护原文，不静默丢弃。

## 可靠性限制与未执行项

进度只在当前浏览器配置与正式来源localStorage，不是长期数据库备份。隐私模式无法可靠识别，结束会话/浏览器清理/故障均可能丢失；需用户主动导出。未实测整个浏览器进程关闭后重启、隐私窗口生命周期、实际断开系统网络冷启动或跨浏览器完整验收。已实测刷新、同来源新标签读取、生产资源以及故障备份，不扩大为上述承诺。

Web Locks不可用时有提示及写前版本检查，但localStorage没有原子比较交换，完全同时多页写入仍有竞态风险，建议单页修改。合并依赖本机时间，时钟回拨或人为修改备份时间可能改变逐条较新判定；导入预览供人工核对。长笔记/练习文字不持久保存，原始恢复副本不自动修复损坏内容。知识前置确认与练习自评都属于本人判断，不证明实际掌握程度。
