## 图表与数据实现

- ECharts受控描述和Zod数据契约；数据rows与chart视觉映射分开。支持bar/line/scatter/histogram/boxplot/heatmap/radar/tree/roc/table；map采用已声明的同源bar降级。没有无底图却声称地图已离线成功的情况，也未额外引入Plotly。
- JSON严格禁止NaN/Infinity；缺失保留null，0保留0；大表ID为字符串。图表有问题、轴、单位、范围、分母、筛选、缺值规则和解释。未知单位不补成“元”“件”。图形最多5000行，散点按原顺序等距取最多3000条并注明；长表100行分页。
- 受支持的类别、指标与时间范围同步更新同源表；多组折线分系列，不跨产品/影片连接。图例只隐藏显示系列，不重算全量分母；缩放仅改变图形视窗。点击可追溯柱/点定位同源表行；树/雷达没有虚构行级追踪。提供重置、表格替代、图形局部错误边界、缺资源提示和重试。
- 按项目analysis/adapters/Pxx/adapter.py为入口，具体变换在phase4_batch_a.py、phase4_projects.py，共享只读/导出在phase4_common.py。原Notebook只解析，不exec/eval，不执行pip、联网采集、原路径写入或pkl加载。
- 构建清单记录输入/适配代码SHA-256、环境、参数、种子、划分、时间和结果哈希。每个项目的课节、输入输出、清洗读取记录、模型版本、受阻原因见phase-04-coverage.json及content-source/learning/manifests/Pxx.json。Python环境精确直接依赖版本见analysis/environments/phase4-requirements.txt；不是所有旧项目环境的完整兼容承诺。
