## 启动方式

双击工程根目录“启动学习平台.cmd”，或：

```powershell
cd D:\项目\data-learning-platform
npm.cmd start
```

启动后访问 http://127.0.0.1:4173 。静态服务仅需要已验证的本机Node，不必安装Python或启动Vite。Ctrl+C停止。交付dist可直接运行；修改代码后执行npm.cmd run build重新生成。临时验收服务会停止，用户启动器负责后续运行。未交付exe，也没有把未来打包工具写成已实现。

开发服务器：npm.cmd run dev，地址127.0.0.1:5173，不能替代正式入口。不要用file://或改来源，浏览器存储按来源隔离。
