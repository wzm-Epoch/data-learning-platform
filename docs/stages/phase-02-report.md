## 数据驱动与维护机制

- content-source/registry.json是上线轻量目录源；categories.json、stages.json定义分类/路线归属。
- content-source/projects/Pxx/project.json是各项目人可维护的详情与字段字典源。
- content-source/knowledge.json为已核实标签、代码引用和知识依赖分支。
- scripts/generate-catalog.mjs校验并生成app/public/content/catalog.json、knowledge-index.json及projects/Pxx/project.json；npm run build自动调用，不需要修改页面。
- scripts/prepare-phase2.py是从当前29项目审计和批准设计导入初始内容的工具，使用标准库读取Notebook/CSV/XLSX XML，不运行分析。它会重建这批导入内容；常规课程编辑或新增项目应编辑内容源并执行build，不应重新导入覆盖人工改编。
- 原content-source/projects.json保留为第一阶段审计导入快照，不再直接作为上线注册表。local-config/paths.json仅用于本机导入与核对，不进入dist。
- Schema从1.0目录升为1.1，反映目录/详情拆分；未写入或迁移学习进度。本阶段不实现第五阶段进度系统。
